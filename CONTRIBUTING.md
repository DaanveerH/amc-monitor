# Contributing

Thank you for taking the time to improve AMC Seat Watch.

Before opening a pull request:

1. Keep the change focused on one problem.
2. Add or update tests for behavior changes.
3. Use synthetic data in code, tests, docs, screenshots, and logs.
4. Run the validation commands in `README.md`.
5. Explain the problem, the chosen approach, and the test evidence.

Do not submit credentials, live Discord or database IDs, private hostnames,
personal preferences, production logs, or third-party application binaries.

Bug reports should include a minimal reproduction and redacted output. Feature
requests should explain the user problem and how the proposal fits the
outbound-only, manual-purchase product boundaries.
